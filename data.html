Using the data

Cite the dataset ID and release year. Tide-gauge heights are relative to the Alder Point station datum, not to a national reference level; the methods note explains how to convert.

Quality flags

Each reading carries a flag: 0 for good, 1 for suspect, 2 for rejected. We never delete rejected values, so a different screening rule can be applied.
